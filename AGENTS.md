# README maintenance

- Keep the Python package under `src/contribrise` and its browser assets under `static`. Avoid runtime dependencies and framework layers.

- Review established, widely used open-source READMEs when changing the public introduction.
- Lead with what the app does, a representative screenshot, and the shortest complete path to running it.
- Keep the English and Japanese READMEs aligned. Put implementation details after the usage guide. Use screenshots in the same language as each README.
- Capture the actual app with fictional usernames and synthetic data, state that in the caption, and inspect the images before publication.
- Check image paths, links, and rendered layout before reporting a README change complete.
